# @nestarc/pagination 0.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the focused 0.2.0 scope from `docs/superpowers/specs/2026-06-14-pagination-0-2-0-design.md`.

**Architecture:** Keep `paginate()` as the public orchestrator. Add focused helpers for keyset cursor encoding/where generation and count strategy resolution, while preserving existing Prisma cursor behavior by default. Extend existing query parsing, Swagger decorators, README, changelog, and package metadata without changing the root public call signature.

**Tech Stack:** TypeScript, NestJS 10/11, Prisma-like delegates, Jest, optional `@nestjs/swagger`.

Add helpers in `paginate.ts`:

```typescript
function resolveCountStrategy<T>(config: PaginateConfig<T>, mode: 'offset' | 'cursor'): CountStrategy {
  if (config.countStrategy) return config.countStrategy;
  if (config.withTotalCount === true) return 'exact';
  return mode === 'offset' ? 'exact' : 'none';
}

async function runCount<T>(
  strategy: CountStrategy,
  where: Record<string, any>,
  delegate: { count: (args: any) => Promise<number> },
  query: PaginateQuery,
  config: PaginateConfig<T>,
): Promise<number | undefined> {
  if (strategy === 'none') return undefined;
  if (strategy === 'custom') {
    if (!config.countQuery) throw new Error('countQuery is required when countStrategy is custom');
    return config.countQuery({ where, delegate, query, config });
  }
  return delegate.count(buildCountArgs(where, query, config));
}
```
